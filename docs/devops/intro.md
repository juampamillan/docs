# DevOps

Esta sección documenta las prácticas de DevOps, incluyendo control de versiones, integración continua y despliegue en la nube.

---

## Principios

1.  **Automatización**: Minimizar intervención manual en builds y deploys.
2.  **Observabilidad**: Logs, métricas y trazas centralizadas.
3.  **Infraestructura como Código**: Configuración versionada y reproducible.
4.  **Staging Environments**: Flujo controlado entre ambientes.

---

## Stack Tecnológico

- **Control de Versiones**: Git con modelo de branching basado en Fast-Forward.
- **CI/CD**: GitLab CI / GitHub Actions.
- **Cloud**: Google Cloud Platform (GCP).
- **Contenedores**: Docker.
- **Orquestación**: Cloud Run (serverless).
