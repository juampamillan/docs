# Desarrollo de Frontend

Esta sección documenta los estándares, arquitectura y mejores prácticas para el desarrollo de interfaces de usuario modernas utilizando **React**, **TypeScript** y una arquitectura de **Microfrontends**.

---

## Stack Tecnológico

- **Framework**: React 18+
- **Lenguaje**: TypeScript
- **Herramienta de Build**: Vite
- **Arquitectura**: Microfrontends (Module Federation)
- **UI Kit**: Material UI (MUI)
- **Estado**: Zustand / Context API
- **Autenticación**: Azure AD (MSAL)
