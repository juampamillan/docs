# Bienvenido a engineering.docs

Este portal reúne **guías técnicas, estándares y patrones de ingeniería de software**
aplicados en proyectos de producción a gran escala. Es un sitio de consulta para
desarrolladores que quieren construir sistemas modernos, mantenibles y escalables.

## Filosofía

Las guías aquí documentadas parten de tres convicciones:

1. **Los principios duran más que las herramientas.** Las tecnologías cambian; Clean
   Architecture, idempotencia y separación de responsabilidades no.
2. **Las decisiones deben ser explícitas.** Cada estándar incluye el razonamiento detrás.
   Sabes qué hacer *y* por qué.
3. **La documentación es parte del código.** Un sistema no documentado es un sistema
   difícil de mantener.
